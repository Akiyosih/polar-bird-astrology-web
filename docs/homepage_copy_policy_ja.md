# 日本語ホームページコピー方針

この文書は、Polar Bird Astrology 公開サイトの日本語ホームページ文言と
UI文言を整えるための公開可能な方針です。

公開repoに置く文書なので、非公開のベンチマークレポート、私的なパス、
内部レビュー記録、生成済みの個人向け鑑定本文はここに入れません。

## 目的

ホームページの文言は、Polar Bird Astrology が何を読み、いま何を公開し、
これからどの導線を準備しているのかを、短く正確に伝えるために書きます。

ホームページは防御的な説明ページではありません。ヒーロー、レポートカード、
CTA では、その面に置ける最も強い明確な主張を書きます。読み方、採用している
占星術スタイル、公開repoへの導線、解釈の境界は `読み方と方針` にまとめます。

現在のサンプル対象は Core Blockchain です。ただし、語り手とブランドは
Polar Bird Astrology です。Polar Bird Astrology は Core Blockchain 専用ブランドでは
ありません。

## 文体

日本語は、落ち着いていて、普通の言葉で、1文に1つの役割を持たせます。
1文は原則として、次のどれかを担います。

- レポート種別や時間軸を示す
- そのレポートが何を読むかを示す
- 読者が何を理解できるかへ翻訳する
- 次に読む場所へ案内する

上品さや美しさは、「静か」「上品」「美しい」と自分で言うことで作りません。
正確な名詞、普通の動詞、短い見出し、余計な説明の少なさで感じさせます。

占星術で自然に言えることは、肯定形で書きます。境界は、見える場所に
免責文を増やすことではなく、主張の範囲、置き場所、不要な事実断定を
書かないことで扱います。

## 面ごとの役割

ヒーロー、レポートカード、CTA では、次を優先します。

- Polar Bird Astrology が何を公開しているか
- 現在の公開レポートが Core Blockchain を読んでいること
- レポート種別と時間軸
- そのレポートから何が分かるか
- 防御的な説明を置かないこと

読み方と方針ページでは、次を扱います。

- 出生図、太陽回帰、新月サイクルの役割
- 人、事業、コミュニティを読むときの言葉の置き換え
- 採用している読み方と公開repoへの導線
- 事実確認が必要な領域
- 必要最小限の具体的な境界

フッターや補足ボックスでは、短い案内だけを置きます。同じ免責を何度も
繰り返しません。

## レポート種別

出生図レポート:

出生図に示される基本構造を読みます。核となる性質、反応のパターン、
長く続く特徴、コミュニティの土台、Core Blockchain らしさの基盤を扱います。

太陽回帰レポート:

その年のテーマと年間の舞台を読みます。どこに焦点が当たりやすいか、
その年に既存の性質をどう使い、どう形にしていくかを扱います。
太陽回帰だけで月ごと・日付ごとの予測をするようには書きません。

新月サイクルレポート:

新月から次の新月までの現在のサイクルを読みます。動きやすいテーマ、
リズム、月相ごとの流れ、観察したいポイントを扱います。プロダクト
ロードマップ、価格予測、一般的な月間チェックリストにはしません。

## Core Blockchain の扱い

日本語サイトのUI、見出し、カード、導線、frontmatterでは、原則として
`Core Blockchain` を使います。`Core` はレポート本文内の読み物としての
自然さを優先する場合に残せます。

`Coreさん` とは書きません。

人間向け占星術の感情表現を Core Blockchain に移すときは、エコシステムの言葉へ
翻訳します。たとえば、月や感情の話は、コミュニティの空気、受け止め方、
反応のリズム、Core Blockchain をめぐる理解や語られ方として扱います。

文が抽象的になる場合は、コミュニティメンバー、開発者、ユーザー、
パートナー、公開説明、参加、運用、信頼、共有理解など、具体的な主語や
対象を使います。

## 公開境界

公開文言では、次を主張・示唆しません。

- Core Blockchain の公式発信であること
- 投資助言、価格予測、市場結果、保証された成果
- プロダクト公開、公式ロードマップ、ローンチの確実性
- このサイトで実際に提供していない購入、ウォレット、サインイン、連携

CorePay 自体の存在や公式サイトへのリンクは扱えます。Polar Bird Astrology 側の
購入導線が未実装の場合は、`準備中`、`soon`、`購入導線を準備しています` のように
状態を明確にします。利用できる決済導線としては書きません。

この境界は、ブランド面で `非公式です`、`投資助言ではありません` を
繰り返して解決しません。原則は、占星術で読める主張だけを書くこと、
事実境界は適切な説明ページに置くこと、支えられない主張を削ることです。

## 読み方の透明性

読み方と方針ページでは、心理占星術、人間性占星術、トロピカル方式、
プラシーダス、ノード方針、計算基準、根拠階層、レポート種別ごとの
読み方を公開できます。

ただし、公開するのはプロジェクトとして採用済みの方法だけです。未整理の
流派差、計算方式、根拠階層は、公開文言ではなく内部検討に残します。

ホームページから読み方と方針ページへリンクする場合は、短く非技術的に
案内します。詳しい説明は読み方と方針ページで行います。

## 作成手順

日本語ホームページ文言を作るときは、次の順で判断します。

1. 置く面を決める。ヒーロー、カード、CTA、フッター、サンプルレポート、
   レポート購入、読み方と方針のどれか。
2. 主語を決める。Polar Bird Astrology、Core Blockchain、レポートのどれか。
3. レポート種別と時間軸を決める。出生図、太陽回帰、新月サイクルのどれか。
4. 占星術で自然に言える最も強い範囲の主張を書く。
5. 境界が必要なら、面に応じて扱う。ブランドUIでは省き、補足文では短く、
   詳細は説明ページに置く。
6. 1文1役になるまで削る。全文を読まなくても意味が分かる文にする。
